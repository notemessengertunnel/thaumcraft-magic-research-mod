[![Download Latest](https://img.shields.io/github/v/release/notemessengertunnel/thaumcraft-magic-research-mod?style=flat-square&label=Download&color=brightgreen)](https://github.com/notemessengertunnel/thaumcraft-magic-research-mod/releases/latest)
[![Forge](https://img.shields.io/badge/Loader-Forge-orange?style=flat-square)](https://files.minecraftforge.net/)

Discover magical aspects in items, research new knowledge in your Thaumonomicon, and wield vis crystals.

## Features

- Aspect research system — scan items to learn their magic
- Thaumonomicon guidebook filled by completing research
- Wand and Staff crafting with vis crystal upgrades
- Infusion Altar for powerful magical item creation
- Taint system — magical pollution that spreads corruption

## Installation

1. Install [Minecraft Forge](https://files.minecraftforge.net/) for your version
2. Download the JAR for your Minecraft version above
3. Place the JAR into your `.minecraft/mods/` folder
4. Launch Minecraft with the Forge profile

## Requirements

- **Mod Loader:** Forge
- **Minecraft:** 1.16.5 / 1.18.2 / 1.19.2 / 1.20.1
